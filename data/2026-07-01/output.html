工作台被模型接管

从科研、代码到手机键盘，AI 正在离开演示页，钻进每天真正产生结果的界面。

模型公司今天不再只比谁更聪明，而是在抢两个更现实的位置：谁能进工作台，谁能进预算。Sonnet 5 降价跑 Agent，Claude Science 盯上实验室，Google 把图像和视频 API 做成低价流水线，中国开源模型继续压进编码榜单，键盘也开始长出 Agent。

以下是你今天需要知道的 5 条全球要闻、4 条模型动态、4 条技术深度，以及我的投资视角和工具箱推荐。

保持好奇，保持吐槽。

📌 今日趋势：Anthropic 一天内把 Sonnet 5 推成默认模型，又端出 Claude Science；Google 把 Nano Banana 2 Lite 和 Gemini Omni Flash 放进开发者流水线；Meituan 用 LongCat-2.0 把 1.6T、1M 上下文和国产芯片训练绑在一起；Acti 则把 Agent 塞到手机键盘里。今天最硬的动作不是发布一个更会聊天的模型，而是把模型塞进科研、编码、媒体生成、移动输入这些真正花钱的工作台。

对中国创作者和企业来说，门槛正在从“会不会用 AI”变成“能不能把 AI 变成固定产能”。视频团队要盯低价高吞吐生成 API，研发团队要盯代码 Agent 的成本和评测证据，垂直行业要盯 Claude Science 这类工作台能不能把专家软件拆掉。单点工具越来越便宜，真正值钱的是把模型接进流程、权限、数据和交付。

接下来 2-4 周重点看三件事：Sonnet 5 的低价窗口会不会逼 OpenAI、Google 跟进 Agent 定价；Gemini 新媒体模型能不能把创意工具价格继续打穿；LongCat-2.0 和 ScarfBench 这类开源/评测信号能否证明 Agent 不只会 Demo，而能改老代码、跑迁移、交结果。

01 Key Intelligence 全球要闻

Anthropic 用 Sonnet 5 降价跑 Agent

来源: Anthropic · 2026-07-01 · 原文链接

Anthropic 发布 Claude Sonnet 5，并称它从 6 月 30 日起成为 Free 和 Pro 计划的默认模型，同时向 Max、Team、Enterprise、Claude Code 和 Claude Platform 开放。平台价在 2026 年 8 月 31 日前为每百万输入 token 2 美元、输出 token 10 美元，之后回到 3 美元和 15 美元；官方强调它面向多步软件工程、工具使用和长任务执行。

Janet 锐评： Anthropic 这刀砍在 Agent 成本上。过去把长任务交给模型像烧钱试运气，现在 Sonnet 5 用中档价格去抢 Opus 才配做的活；开发者该开心，但也该紧张，Agent 一旦便宜，粗糙外包和低端代码服务会先被压价。

Claude Science 直接盯上科研工作台

来源: STAT / TechCrunch / NVIDIA · 2026-07-01 · 原文链接

Anthropic 推出 Claude Science，一个面向科研人员的 AI workbench，主打把数据库、计算管线、模型调用和研究流程放进同一环境。STAT 和 TechCrunch 均在 6 月 30 日报道了这项产品，NVIDIA 也同步介绍 BioNeMo Agent Toolkit 进入 Claude Science，帮助生命科学研究者搭建加速工作流。

Janet 锐评： 科研 AI 的关键已经从会背论文，转向少开十个工具。Claude Science 抢的是实验室的工作台入口，未来收费点会落在数据、模型、算力和复核串联起来的生产环境；国内科研软件厂商要醒了。

Google 推 Nano Banana 2 Lite 和 Gemini Omni Flash

来源: Google · 2026-07-01 · 原文链接

Google DeepMind 在 6 月 30 日发布 Nano Banana 2 Lite 和 Gemini Omni Flash。前者是 Nano Banana 系列中更快、更低成本的图像模型，已进入 Google AI Studio、Gemini API 和 Gemini Enterprise Agent Platform；后者面向高质量视频生成和对话式编辑，Google 还强调两者可以在 Interactions API 里串联使用。

Janet 锐评： Google 又在用免费和低价打市场。图片先低成本生成，再直接动画化成视频，这对创作者是好消息，对只会套壳卖图的 SaaS 是坏消息；未来收费点会从“生成一张图”移到批量、版权、模板和交付速度。

Meituan 发布 1.6T 编码模型 LongCat-2.0

来源: LongCat / WinBuzzer / OpenSourceForU · 2026-07-01 · 原文链接

Meituan 在 6 月 30 日公开 LongCat-2.0，外部报道称其为 1.6 万亿参数 MoE 编码模型，主打 1M token 上下文、Agentic coding，并称训练使用 5 万颗国产计算芯片。模型以 MIT License 开源发布，相关页面称它此前与 OpenRouter 上的匿名模型 Owl Alpha 有关联。

Janet 锐评： 美团这次最狠的是叙事组合拳：国产芯片、超长上下文、编码榜单、MIT License 全塞在一条新闻里。真能不能扛复杂工程还要看实测，但中国模型已经学会用开源和成本去打全球开发者心智。

Etched 拿 50 亿美元估值卖 AI 专用芯片

来源: TechCrunch · 2026-07-01 · 原文链接

TechCrunch 6 月 30 日报道，AI 芯片创业公司 Etched 已达到 50 亿美元估值，并称其 Sohu AI 芯片相关销售订单达到 10 亿美元。公司定位是 NVIDIA 的竞争者，押注为 transformer 推理打造专用芯片，在高吞吐 AI 推理场景里争夺成本优势。

Janet 锐评： 芯片创业公司能拿 10 亿美元订单，说明市场已经不只想买 NVIDIA 的货。风险也很直白：专用芯片赌的是模型架构稳定，一旦主流推理路线换挡，今天的捷径明天可能变库存。
02 Model Updates 模型动态

Claude Sonnet 5 支持 1M 上下文和 128K 输出

来源: Anthropic Platform Docs · 2026-07-01 · 原文链接

Anthropic 平台文档显示，Claude Sonnet 5 的模型名为 claude-sonnet-5，支持 1M token 上下文窗口和 128K max output tokens，并继承 Claude Sonnet 4.6 的主要工具与平台能力，但不支持 Priority Tier。官方把它放在更适合长程 Agent 和代码任务的价格带。

Janet 锐评： 1M 上下文已经从炫技变成门票，老代码库、长合同、研究资料终于能塞进一次任务。问题是上下文越长，垃圾也越多；会不会筛选材料，比会不会把窗口填满更值钱。

GitHub Copilot 首日接入 Claude Sonnet 5

来源: GitHub Blog · 2026-07-01 · 原文链接

GitHub 在 6 月 30 日的 changelog 中宣布 Claude Sonnet 5 已在 Copilot 中 generally available，用户可以通过 Copilot model picker 选择该模型。Anthropic 新模型发布当天即进入主流开发者入口，说明模型分发正在跟 IDE 和代码助手深度绑定。

Janet 锐评： 模型发布当天进 Copilot，比发一堆 benchmark 更有杀伤力。开发者不会每天读论文，但会每天打开 IDE；谁占住 model picker，谁就有机会把 API 费变成习惯税。

Nano Banana 2 Lite 主打高吞吐图像生成

来源: Google DeepMind · 2026-07-01 · 原文链接

Google 称 Nano Banana 2 Lite 是 Nano Banana 家族中最快、最具成本效率的 Gemini Image 模型，目标是高吞吐、速度和规模化。它已经进入 Google AI Studio、Gemini API、Gemini Enterprise Agent Platform，并逐步进入 AI Mode in Search、Gemini app 等消费端入口。

Janet 锐评： 图像模型开始拼吞吐，意思就是生成图正在从“惊艳一下”变成“批量出货”。创作者最该盯 API 成本曲线：当一张图便宜到接近素材消耗品，赚钱点只能往策划、选片、版权和分发迁。

LongCat-2.0 用 MIT License 抢开发者

来源: LongCat / Cursor Forum · 2026-07-01 · 原文链接

LongCat-2.0 页面显示，该模型主打 1.6T MoE、1M 上下文和 Agentic coding，并以 MIT License 发布。外部报道同时提到模型权重和直接平台确认仍需要继续观察，开发者社区已经开始讨论 Cursor 等工具是否应接入该模型。

Janet 锐评： 开源模型打开发者，最有效的武器就是低门槛许可证。LongCat-2.0 如果实测过关，会给国内模型出海一个样板：别只讲中文市场，直接去抢全球 Coding Agent 的工具链入口。
03 Tech Insights 技术深度

Hugging Face 模型页挂上 Every Eval Ever

来源: Hugging Face · 2026-07-01 · 原文链接

Hugging Face 6 月 30 日宣布在模型页面展示 Every Eval Ever 结果。该功能把来自评测社区的多维结果放到模型页旁边，目标是让模型选择不再只依赖单个排行榜或厂商自报成绩。

Janet 锐评： 榜单终于开始从营销海报变成采购证据。模型太多以后，客户真正缺的是可复查、可对比、能解释的评测；国内模型厂如果还只贴一张总分图，销售会越来越难。

IBM 用 ScarfBench 专测 Java 迁移 Agent

来源: IBM Research / Hugging Face · 2026-07-01 · 原文链接

IBM Research 6 月 30 日在 Hugging Face 发布 ScarfBench，用企业 Java framework migration 任务评测 AI Agent。该基准关注真实企业迁移中的代码理解、修改、依赖处理和工程约束，不是简单刷题。

Janet 锐评： 老系统迁移才是 Agent 的照妖镜。会写新项目不稀奇，能把银行、保险、制造业的 Java 老代码迁干净才值钱；ScarfBench 这种基准会逼 Coding Agent 从 Demo 走向脏活。

Couchbase 推 AI Data Plane 给 Agent 本地记忆

来源: VentureBeat · 2026-07-01 · 原文链接

VentureBeat 6 月 30 日报道，Couchbase 推出 AI Data Plane，主打让 Agent memory 和 vector search 在边缘或本地运行，解决云端不可达、数据主权和上下文延迟问题。文章把它放在企业 AI Agent 需要随处获取 context 的背景下讨论。

Janet 锐评： Agent 失控很多时候源于上下文断电，不一定是模型笨。Couchbase 押的是本地记忆和边缘检索，适合那些不能把数据全丢给云的行业；做企业 AI 的团队，别再把 RAG 当万能胶。

NVIDIA BioNeMo 进入 Claude Science

来源: NVIDIA · 2026-07-01 · 原文链接

NVIDIA 6 月 30 日发文称，BioNeMo Agent Toolkit 将进入 Anthropic 的 Claude Science，帮助生命科学研究者用代理工作流调用 NVIDIA BioNeMo 模型、库和加速流程。该合作把基础模型、专业生物模型和加速计算放进同一个科研工作台。

Janet 锐评： AI for Science 不会靠一个聊天框赢，最后拼的是谁能把专业模型、算力和研究流程打包。NVIDIA 很清楚：只卖 GPU 不够，还要把 GPU 绑定到科学家每天打开的软件里。
04 Investment & Prediction 投资视角 · 大胆预测

今日核心预测

Acti 融资 530 万美元押 Agent 键盘

来源: TechCrunch · 2026-07-01 · 原文链接

TechCrunch 6 月 30 日报道，Acti 获得 530 万美元种子轮融资，由 BITKRAFT Ventures 领投。公司把 AI Agent 放进智能手机键盘，让用户在邮件、聊天、社交和移动工作流中直接调用 Skills，并计划建设可分享的 Skills marketplace。

Janet 锐评： 键盘是最狠的入口，因为它贴着所有 App。Acti 的风险是用户会不会烦，机会是如果 Agent 能在输入瞬间帮你执行任务，它就不需要说服用户再打开一个 AI 应用。

Etched 10 亿美元订单证明推理芯片还有窗口

来源: TechCrunch · 2026-07-01 · 原文链接

Etched 称其 AI 专用芯片订单达到 10 亿美元，估值升至 50 亿美元。投资逻辑很明确：当推理负载持续增长，市场会寻找比通用 GPU 更便宜、更高吞吐的专用路径。

Janet 锐评： 资本现在买的是 NVIDIA 之外的逃生门。只要推理账单继续膨胀，专用芯片就有故事；但这门生意靠交付、软件栈和客户锁定说话，任何一环掉链子，估值都会反噬。

Meituan 开源模型点燃国产芯片叙事

来源: LongCat / TradingView · 2026-07-01 · 原文链接

LongCat-2.0 把 1.6T 参数、1M 上下文、Agentic coding 和国产芯片训练放在同一套叙事里。对投资人而言，这不只是模型新闻，也是中国 AI 基建、应用场景和开源分发能力的一次集中展示。

Janet 锐评： 中国 AI 投资最缺的是能被开发者反复验证的产品。LongCat-2.0 如果只是发布会参数，热度很快散；如果真能在编码和 Agent 工具里跑出稳定口碑，美团会打开一个比外卖更性感的资本想象。
05 Creator Toolbox 创作者工具箱

今日工具箱

Acti 推手机键盘 AI Agent

来源: Acti / TechCrunch · 2026-07-01 · 原文链接

Acti 是一个智能手机键盘产品，用户可以在任意输入场景中调用 AI Skills，例如读取实时赛事信息、插入 Polymarket 链接或执行跨应用任务。公司计划让 Skills 可以私有使用，也可以进入 marketplace 分享。

Janet 锐评： 推荐给重度移动办公和社媒运营的人试。它的价值不在“键盘更聪明”，而在少切 App、少复制粘贴、少把任务丢回聊天框；如果执行稳定，移动端 Agent 入口会先从键盘长出来。
