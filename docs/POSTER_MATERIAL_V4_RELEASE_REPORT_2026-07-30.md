## 1. 发布范围

本候选把三张 Janet 宣传海报中的深绿信号场、暖光编辑台和奶白光桌提炼成共享设计系统，并覆盖：

- 首页与信号地球。
- Janet Logo、顶部导航、背景音乐和土豆中心。
- 晨报归档、新生成晨报模板、作品库和项目详情。
- GPT Image 2 提示词手册与镜场计划实验观测站。
- 穿梭宇宙、错位名场面、404 和密码重置页。
- Marvel 页面仅接入必要系统修复，保留独立视觉。

历史晨报成品没有被批量重写；新模板和后续生成内容使用 V4。

## 6. 回滚方法

发布前先把远程回滚引用固定到 V4 前正式基线。正式发布只允许非强制更新。

若上线后触发任一强制回滚条件：

1. 从 `rollback/pre-poster-material-v4-20260729` 创建恢复提交。
2. 使用 `git revert` 或正常合并恢复，不使用 `reset --hard` 和强推。
3. 重新触发 GitHub Pages。
4. 验证首页、晨报、作品库、GPT 手册和镜场五类 URL。
