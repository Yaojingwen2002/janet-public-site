# 镜场计划

镜场计划是 Janet 的影视视觉方法项目：把电影视觉拆成可分析、可转译、可生成、可审核的创作系统。

当前它仍是 Janet 主站里的研究入口和归档区，不是完整独立产品站。长期方向是拆成独立项目，承载方法论、Prompt Builder、测试系统、生成记录和审核后台。

## 公开边界

公开仓库只放可读文档、迁移说明、候选表和测试摘要。

不直接公开：

- 原片参考帧
- 5 秒视频切片
- 未审核生成候选图
- 可识别剧照复刻素材
- 含导演名、片名、演员名、角色名的生产 prompt

这些素材应留在本地目录、私有存储或未来独立项目的 private bucket。

## 产品方向

镜场计划未来应拆成独立项目：

- 方法论页：七层视觉分析和安全转译。
- Prompt Builder：用途、场景、主体、构图、光线、色彩、道具、不变量、禁止项。
- 样板库：描述性视觉模板，不直接复刻具体电影帧。
- 实验记录：H1-H4/H5 测试、评分表、失败案例库。
- 审核规范：来源台账、风险标签、AI 标识和发布规则。

主站只保留入口、品牌背书和精选公开案例。
