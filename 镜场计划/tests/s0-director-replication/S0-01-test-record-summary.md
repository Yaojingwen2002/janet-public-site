用途：内部测试归档。公开页面只使用描述性转译和安全转译，不公开原片参考帧，不发布可识别剧照复刻素材。

## 当前测试目标

S0-01 用作单图校准样本，重点验证：

- 人物关系：右侧人物更靠前、更从容、更有主导性；左侧人物更警觉、更被动。
- 空间层次：前景人物、中景旧墙、后景树叶和院落结构仍然可读。
- 色彩系统：白天戏明亮但不过曝；中间调要厚，暗部可读，高光受控。
- 肤色：保留暖红橙血色，避免灰、绿、白、蜡像感。
- 合规转译：最终生成 prompt 必须避开导演名、片名、演员名、角色名和具体剧照复刻。

## 迭代结论

第一轮 A/B/C：

- A：双人站位和身份方向成立，但画面偏淡，像干净现代剧照。
- B：亮度接近白天戏，但广告感强，低对比。
- C：空间关系最好，可作为后续基础，但缺原片厚度。

中段 D/E/F/G：

- D/E：厚重感增强，但墙面和衣服过脏、过度做旧。
- F：去脏后更清洁，但灰雾和低饱和仍重。
- G：构图稳定，但出现明星脸风险，肤色被青绿吃掉。

当前较优 H/I：

- 中间调饱和度、皮肤红润、墙面色彩密度明显改善。
- 右侧人物的主导性更明确，左侧警觉感存在。
- 旧城墙、中景和后景树叶的空间关系更清楚。
- 衣料厚重和丝绸/缎面反光成立。

## 仍需监控

- 不能再蒙灰。
- 青绿只能留在暗部和中性色，不能吃到皮肤。
- 人物脸必须继续避免任何明星相似。
- 背景不能过度干净或现代景区化。
- 衣服褶皱需要少而大，避免细碎噪声。
- 墙面要旧、晒过、有历史感，但不能脏成废墟。

## 评分表 v0.1

| 项目 | 通过标准 | 失败表现 |
| --- | --- | --- |
| 角色原创性 | 人物有时代感但不撞脸任何明星 | 像任何已知演员或公众人物 |
| 人物关系 | 右侧更靠前、更主导；左侧警觉被动 | 两人权力平均化 |
| 肤色 | 红润、暖、活，有血色 | 灰、绿、白、蜡像、无血色 |
| 中间调 | 皮肤、墙、衣服有密度和饱和 | 低饱和灰雾、淡、薄 |
| 暗部 | 抬黑但干净，有细节 | 死黑、灰雾、脏绿、发泥 |
| 高光 | 亮但不爆，白衬衫和额头受控 | 刺眼死白或整体过曝 |
| 墙面 | 旧、晒过、有历史感但不脏 | 破败、污渍过重、像废墟 |
| 衣料 | 厚重、大褶皱、细褶少 | 粗布、乞丐感、褶皱噪声多 |
| 空间 | 前景人物、中景墙、后景树叶可读 | 背景糊成色块或现代景区 |

## 下一步

1. 继续以 S0-01 为单图校准样本。
2. 先稳定肤色、青绿偏移、中间调密度和明星脸问题。
3. S0-01 连续 3 次生成都通过评分表后，再推进 `02_huang_white_interior_closeup.jpg`。
4. 每一张母图都要先做：
   - 原片语境
   - 角色状态
   - 空间关系
   - 一级调色
   - 二级区域
   - A/B/C 三版提示词
   - 评分表

## 公开安全规则

- 内部分析可以保留原片语境和角色状态。
- 生成提示词只使用 B/C 转译。
- 公开候选 prompt 不出现导演名、电影名、演员名、角色名、品牌、logo、水印或已知剧照构图。
- 参考帧和生成图默认不提交公开仓库。
